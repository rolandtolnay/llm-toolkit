# Business Bundle

Curated business/offer strategy skills from `alexsmedile/hormozi-skills`, trimmed for fresh projects where an LLM needs strong commercial judgment without loading redundant overlapping workflows.

Use these as strategy lenses. They are not market evidence; pricing, demand, and channel claims still need research or competitor proof.

## Core skills included

- `market-research` — select a buyer segment, surface pain, validate demand.
- `business-model` — choose monetization model and scaling path.
- `productize` — convert bespoke work into repeatable products and offer ladders.
- `dfy-dwy-diy` — choose delivery model: done-for-you, done-with-you, or self-serve.
- `hormozi-offer` — build the core offer: avatar, outcome, obstacles, solution map, positioning.
- `audit-offer` — review an existing offer against dream outcome, likelihood, time delay, effort, pricing, and messaging.
- `pricing-strategy` — anchor price to value, delivery model, tiers, and experiments.
- `landing-page-copy` — structure a sales/landing page from the offer.
- `offer-angles` — generate positioning angles and testable message frames.
- `objection-destroyer` — map objections to belief shifts, proof, and product fixes.
- `value-perception` — improve naming, packaging, framing, stacking, and anchoring.
- `value-accelerator` — shorten time-to-first-value and onboarding friction.

## Intentionally omitted upstream skills

These were read end-to-end and excluded because the overlap is still too strong for a default fresh-project bundle:

- `idea-to-product` — umbrella workflow duplicating market, offer, pricing, hooks, objections, and ladder work. `hormozi-offer` plus the focused skills are clearer.
- `hormozi-pitch` — useful for pitch-only work, but overlaps with `hormozi-offer`, `landing-page-copy`, `pricing-strategy`, and `objection-destroyer`.
- `bonus-stack` — mostly covered by offer/value/objection skills and can encourage gimmicky bonus stacking.
- `hormozi-hooks` — narrow content/ad hook generator; `offer-angles` is the better strategic default.
- `effort-reduction` — duplicated by `value-accelerator` for commercial onboarding and time-to-value work.

Restore an omitted skill only when that exact output is the project goal, e.g. ad hook generation or a standalone pitch document. Do not install the omitted skills by default.
