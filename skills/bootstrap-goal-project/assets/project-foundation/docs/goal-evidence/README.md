# Goal evidence

Keep compact tracked evidence that is necessary to reconstruct a goal verdict. Create one directory per goal and link it from `docs/goal-log.md`.

Good evidence includes selected screenshots, sanitized fixture comparisons, short judge results, or concise traces that directly support a rubric item.

Do not store secrets, credentials, full build logs, caches, temporary workspaces, production data, or copies of real user data. Keep bulky transient output in an ignored local directory and distill the relevant facts into the goal log.
